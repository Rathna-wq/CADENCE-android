CADENCE is an motion intelligence and personal safety application designed to identify unusual movement patterns and potential distress situations through real-time motion monitoring. The system utilizes smartphone sensors, including the accelerometer and gyroscope, to capture movement data and employs a Machine Learning model developed using Python and Scikit-learn to classify movement patterns such as stationary, walking, running, and sudden stops. The trained model is converted into Java-compatible code using m2cgen and integrated into an Android application, enabling on-device movement classification without requiring continuous cloud connectivity. CADENCE aims to extend basic motion classification into intelligent distress detection through temporal movement analysis, with the goal of triggering emergency alerts and sharing location information with designated contacts.
Our vision is to transform everyday smartphone motion sensors into an accessible, intelligent, and proactive personal safety solution.
